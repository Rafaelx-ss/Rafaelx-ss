## 🚀 About Me

I'm **Rafael Solís**, a 24-year-old software architect from Mérida, Yucatán, Mexico 🇲🇽, with a degree in Software Engineering. I design and build whole systems — database, API, web and mobile clients, and the server they run on.

Most of my work is in the fuel distribution industry, where a wrong number isn't a bug: it's a report to Mexico's tax authority that doesn't add up. That constraint shapes how I build — the data model comes first, and correctness isn't something you bolt on at the end.

### 💼 Professional Experience

- **Brentec Soluciones Tecnológicas — Software Architect (Feb 2025 – Present)**: Architecture for more than half a dozen simultaneous systems in the fuel distribution industry, end to end from the database to server deployment. Read Mexico's SAT volumetric-control regulation in full to define how the JSON submitted to the authority is generated and validated.
- **Adventure Planet Group — Software Architect (Jun 2025 – Present)**: Moved a tour-booking business off a set of separate WordPress sites onto a single Next.js architecture with a Laravel backend. Designed the system that automates buying and configuring the domain for every new site, and integrated Stripe as the payment gateway.
- **CodyExpert — Full-Stack Developer (Apr 2024 – Jan 2025)**: Management panel for fuel-service establishments with dashboards, billing, policy generation and delivery guides. Also a distribution-route tracking platform for a distributor of an international beer brand.
- **Osaka Esports — Full-Stack Developer (Jul 2022 – Oct 2023)**: Maintained a production system managing esports teams and players, in plain JavaScript with no framework, on a codebase I didn't design from scratch.
